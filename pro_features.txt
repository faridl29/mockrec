MOCKREC – FITUR PRO & STRATEGI MONETISASI

====================================
KONSEP UTAMA
============

Fitur PRO harus memberikan value tinggi:

* menghemat waktu developer
* mempermudah testing
* mengurangi ketergantungan backend

Jika fitur tidak membuat kerja developer lebih cepat atau lebih mudah,
maka tidak layak dijadikan fitur berbayar.

====================================
FITUR PRO (PRIORITAS UTAMA)
===========================

1. EXPORT & IMPORT MOCK (WAJIB)

---

Masalah:

* Data mock hanya ada di device
* Tidak bisa dibagikan ke tim

Solusi:

* Export mock ke file JSON
* Import mock dari file

Fungsi:
Mockrec.exportToFile("mock.json");
Mockrec.importFromFile("mock.json");

Value:

* Bisa share ke QA / tim
* Bisa reuse antar project
* Tidak perlu record ulang

---

2. ERROR SIMULATION (WAJIB)

---

Masalah:

* Sulit test error API (500, 401, dll)

Solusi:

* Simulasi error tanpa backend

Fungsi:
Mockrec.setError("/login", 500);

Value:

* QA bisa test error scenario
* Developer bisa handle edge case
* Sangat penting untuk production testing

---

3. DELAY SIMULATION

---

Masalah:

* Tidak bisa test loading state

Solusi:

* Tambahkan delay pada response

Fungsi:
Mockrec.setDelay("/user", Duration(seconds: 2));

Value:

* Test UX loading
* Simulasi kondisi network lambat

---

4. PERSISTENT STORAGE

---

Masalah:

* Data mock hilang saat app restart

Solusi:

* Simpan ke disk (Hive / file / SQLite)

Value:

* Data tetap ada
* Lebih stabil untuk development

---

5. SELECTIVE MOCKING

---

Masalah:

* Tidak semua endpoint ingin di-mock

Solusi:

* Pilih endpoint tertentu saja

Fungsi:
Mockrec.mockOnly(["/user", "/profile"]);

Value:

* Kombinasi real API + mock
* Fleksibel untuk dev & QA

---

6. MOCK EDITOR (ADVANCED)

---

Masalah:

* Tidak bisa ubah response

Solusi:

* Edit JSON response secara manual

Value:

* Bisa inject data custom
* Powerful untuk demo & testing

---

7. MOCK SCENARIO

---

Masalah:

* Satu endpoint butuh banyak kondisi

Solusi:

* Simpan beberapa skenario

Fungsi:
Mockrec.useScenario("success");
Mockrec.useScenario("error");

Value:

* QA bisa test berbagai kondisi
* Lebih fleksibel
